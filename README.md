# 기업건강검진 — 코스닥 상장사 고유 재무위험 진단

한국은행 ECOS(거시지표)와 DART(전자공시, 재무제표) Open API 데이터를 이용해 코스닥 상장사의
**거시경제 요인을 제거한 기업 고유(idiosyncratic) 재무위험**을 계산하고, 실제 상장폐지 이력을
기반으로 학습한 모델로 위험점수(0~100)를 보여주는 개인 프로젝트입니다.

> ⚠️ **면책조항**: 이 사이트는 개인 포트폴리오/학습 목적으로 만든 데모입니다. 표시되는
> 위험점수는 소규모 표본으로 학습된 실험적 모델의 결과이며 통계적으로 검증되지 않았습니다.
> **실제 투자 판단, 신용평가, 거래 의사결정에 사용해서는 안 되며**, 특정 기업의 재무 건전성을
> 공식적으로 나타내지 않습니다. 표시된 기업명은 모델 검증을 위한 예시일 뿐입니다.

## 무엇을 보여주나

- 기업별 위험점수(0~100)와 "왜 이 점수가 나왔는지"에 대한 지표별 기여도 설명
- 재무지표 9종의 연도별 추이 — 원지표와 "거시요인을 제거한 고유위험" 비교
- 동종업계(또는 비교기업 전체) 평균 대비 해설 텍스트
- 완전자본잠식처럼 규정상 명확한 위험 신호에 대한 규칙 기반 보정

## 아키텍처

```
DART Open API ──┐
                 ├─▶ 데이터 수집(collect.py) ──▶ 재무비율 계산(features.py)
ECOS Open API ──┘                                     │
                                                        ▼
                                     라벨링(labels.py, 우측절단 구간 제외)
                                                        │
                                                        ▼
                        거시요인 제거 — 학습구간 적합(fit) → 전체 적용(apply)
                                    (macro_adjust.py, 패널회귀)
                                                        │
                                                        ▼
                              추세·규모 피처 추가(trend_features.py)
                                                        │
                                                        ▼
                     class-weighted 로지스틱 회귀 + 임계값 튜닝(model.py)
                                                        │
                                                        ▼
                                        위험점수 산출(score.py) + 자본잠식 규칙 보정
                                                        │
                        ┌───────────────────────────────┴───────────────────────────────┐
                        ▼                                                                 ▼
              FastAPI + React (풀스택 데모)                              Streamlit (원클릭 배포용 데모)
```

두 프론트엔드(React / Streamlit) 모두 같은 사전 계산 결과(`backend/data/processed/`)를 읽기만
하므로, 배포된 데모에는 DART/ECOS API 키가 필요 없습니다. 키는 데이터를 새로 수집·재학습할
때만 필요합니다.

## 방법론

### 1. 데이터

- **DART**: `fnlttSinglAcntAll` API로 연결/개별 재무제표(2015~2025) 수집
- **ECOS**: 한국은행 기준금리(722Y001) 시계열
- **KRX KIND**: 코스닥 상장사 전체 목록, 2015년 이후 상장폐지 이력 전체(사유 텍스트 포함).
  표본 확대를 위해 자본잠식·감사의견거절처럼 시장 구분과 무관하게 동일한 재무적 기준으로
  판단되는 KOSPI 상장폐지 사례(2015~2022년, 12개사) 일부도 함께 포함했다.

### 2. 재무지표(9종) + 추세·규모 피처

기본 재무지표 9종: ROA, ROE, 영업이익률, 부채비율, 유동비율, 자기자본비율, 이자보상배율,
영업현금흐름/총자산, 매출액증가율. 자기자본이 0 이하(완전자본잠식)인 경우 부채비율/ROE의
부호가 뒤집혀 오히려 안전해 보이는 착시가 생기므로, 고정 상하한값으로 대체하고 별도의
`capital_impairment` 플래그로 모델에 노출한다.

상장폐지는 한 시점의 수준보다 악화 속도·지속 기간이 중요한 신호인 경우가 많아
(`trend_features.py`), 다음을 추가로 피처화한다: 지표별 전년 대비 변화량(고유위험 기준),
최근 2년 연속 영업손실/영업현금흐름 마이너스 여부, 기업 규모(총자산 log 변환).

### 3. 거시요인 제거 — fit(학습구간)/apply(전체) 분리

각 재무비율을 `비율 ~ 기준금리 + 산업더미`로 패널회귀(OLS)한 뒤 잔차를 "기업 고유 위험"으로
사용한다. **회귀는 반드시 학습구간 데이터에만 적합(`fit_macro_models`)하고, 검증·예측 구간에는
그 계수를 적용(`apply_macro_models`)만 한다** — 전체 기간에 한 번에 회귀를 돌리면 미래 구간의
정보가 과거 구간 잔차 계산에 새어 들어가는 데이터 누수가 생기기 때문이다(StandardScaler를
학습구간에만 fit하는 것과 같은 원칙). 표본이 작은 산업군에서는 산업더미를 생략하거나
평균차감으로 대체하고, 학습구간에 없던 산업코드가 검증구간에 나타나면 그 행만 평균차감으로
대체한다.

### 4. 라벨링과 우측절단(right-censoring)

KIND 상장폐지 이력 중 재무적 사유(감사의견 거절, 자본잠식, 부도, 실질심사 등)로 분류된 건에
한해, **폐지연도-1 회계연도**에 라벨 1을 부여한다(그 해 재무제표로 "내년도 폐지 여부"를 맞추는
문제 설정). 합병·SPAC소멸·자진상장폐지 등은 재무위험과 무관하므로 제외한다.

사업연도 Y의 라벨은 "Y+1년에 폐지됐는가"를 뜻하므로 Y+1년이 완전히 지나야 확정된다. 가장 최근
사업연도는 아직 그 해가 끝나지 않아 label=0으로 보이지만 실제로는 폐지될 수 있는 우측절단
상태라, 학습·검증에서는 제외하고 예측(스코어링) 전용으로만 쓴다(`latest_label_confirmed_year`).

### 5. 모델과 임계값

class-weighted 로지스틱 회귀(L2 정규화, 정규화 강도는 교차검증으로 선택) + 완전자본잠식 규칙
기반 위험점수 하한(70점) 보정. 계수 × 지표값으로 각 지표의 기여도를 계산해 위험도 산출 근거를
투명하게 보여준다.

`class_weight="balanced"` 특성상 0.5는 "실제 위험확률 50%"를 뜻하지 않는다. 학습구간 내부
교차검증(out-of-fold) 예측만으로 F2 점수가 최대인 임계값을 별도로 고르고(`_select_f2_threshold`),
검증 결과에는 0.5 기준과 튜닝된 임계값 기준을 나란히 보고한다. 양성 사례가 희귀한 데이터라
ROC-AUC 외에 PR-AUC(average precision), 부트스트랩 95% 신뢰구간, Precision/Recall@K(상위 N개
기업 조사 시나리오)도 함께 계산한다.

## 알려진 한계

- **표본이 매우 작다**: 검증구간(2023~2024) 양성(폐지) 사례가 25건뿐이라, ROC-AUC 점추정치의
  95% 부트스트랩 신뢰구간이 [0.73, 0.90]으로 넓다. 학습구간 EPV(변수당 이벤트 수)도 낮은
  편이라(정규화 강도를 하드코딩하지 않고 교차검증으로 고르는 이유), 이 정도 표본에서는
  소수점 둘째 자리 단위의 AUC 변화를 "개선"으로 해석하면 안 된다.
- **holdout AUC는 최종 배포 모델의 성능을 그대로 대변하지 않음**: 시계열 검증은 2015~2022년
  학습 -> 검증 구간으로 성능을 확인하지만, 검증이 끝나면 배포용 모델은 확정된 데이터를 최대한
  다 쓰기 위해 검증 구간까지 포함해 재학습한다(`train_production_model`). 따라서 실제 배포
  모델은 holdout에서 측정한 것보다 조금 더 나을 수도, 다를 수도 있다.
- **일부 지표 계수 부호 불안정**: ROA처럼 표본 특성상 이론과 반대 부호로 학습되는 지표가 있다.
  VIF로 다중공선성을 확인해봤지만 원인이 아니었고(완전자본잠식처럼 명확한 경우만 규칙으로
  보정), 소표본 자체의 특성일 가능성이 높다.
- **거시변수 1종**: 기준금리만 사용했다. GDP성장률, 산업생산지수 등으로 확장하면 더 정교해진다.
- **상장폐지 사유가 재무비율로 설명하기 어려운 경우까지 뭉뚱그려 라벨링됨**: 공시 미제출,
  경영 투명성 문제처럼 재무비율과 인과관계가 약한 사유도 같은 label=1로 처리한다. 사유별로
  분리를 시도해봤으나(감사범위제한·KRX 실질심사 표준문구 등 제외) 이미 작은 표본이 3분의 1
  이하로 줄어들어 오히려 신뢰할 수 없는 결과가 나와 채택하지 않았다 — 표본을 늘리지 않는 한
  이 방향은 시도하기 어렵다.
- **매칭 실패**: 719개사 시도 중 667개사만 DART 재무자료를 확보했다(사명변경·특수문자·매칭
  실패 등으로 52개사 제외). `resolve_corp_code`는 부분일치 대신 공백/법인형태 표기 차이만
  정규화해 완전히 같아지는 경우만 매칭하도록 만들어, 다른 회사 데이터가 섞여 들어가는 조용한
  오매칭 위험을 없앴다(대신 애매한 경우는 매칭 실패로 남는다).

## 로컬 실행

```bash
cd backend
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements-dev.txt   # 전체 개발(수집+API+모델 재학습)
# 또는
./.venv/Scripts/python.exe -m pip install -r requirements.txt       # Streamlit 데모만 볼 때

cp .env.example .env   # DART_API_KEY, ECOS_API_KEY 입력 (재수집/재학습 시에만 필요)

./.venv/Scripts/python.exe scripts/build_universe.py   # 유니버스 시드 생성 (주의: 재실행하면
                                                         # KOSPI 추가분·종목코드 백필이 코스닥
                                                         # 전용 스크래핑 결과로 덮어써진다 —
                                                         # 이미 완성된 delisted_companies.csv가
                                                         # 있다면 이 단계는 건너뛸 것)
./.venv/Scripts/python.exe scripts/run_pipeline.py      # 수집 → 지표 → 모델 → 위험점수

./.venv/Scripts/python.exe -m streamlit run streamlit_app.py   # Streamlit 데모
./.venv/Scripts/python.exe -m uvicorn app.main:app --port 8000 # FastAPI 서버 (React용)
```

```bash
cd frontend
npm install
npm run dev   # React 프론트엔드 (FastAPI가 떠 있어야 함)
```
